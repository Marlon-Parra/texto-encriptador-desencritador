🔐 Encriptador / Desencriptador de Texto

Este proyecto permite encriptar y desencriptar textos mediante un algoritmo básico de sustitución de letras.
Fue creado con HTML, CSS y JavaScript, y cuenta además con un historial de acciones realizadas.

🚀 Funcionalidades principales

✔ Encriptar texto
✔ Desencriptar texto
✔ Copiar el resultado al portapapeles
✔ Validación del texto ingresado
✔ Historial de textos procesados

🧠 ¿Cómo funciona la encriptación?

El programa reemplaza ciertas vocales por cadenas de texto específicas:

Letra	Sustitución
e	enter
i	imes
a	ai
o	ober
u	ufat

Ejemplo de encriptación:

Texto original: gato
Texto encriptado: gaitober

Y con el proceso inverso:

Texto desencriptado: gato

▶️ Cómo usar la aplicación

Abrir el archivo index.html en tu navegador.

Escribir un texto en el campo “Texto”.

Presionar el botón Encriptar o Desencriptar.

Copiar el resultado con el botón Copiar resultado.

Visualizar el historial de acciones en la parte inferior.

🛡 Validaciones del sistema

El proyecto:

✔ Convierte mayúsculas a minúsculas
✔ Elimina tildes automáticamente
✔ No permite caracteres especiales que no sean letras, números o espacios

Ejemplos de caracteres inválidos que se eliminan:

@ # $ % & * ¡ ! ¿ ? á é í ó ú
